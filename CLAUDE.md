# Stack e convenções do projeto

- Este projeto usa Next.js, Tailwind CSS, shadcn/ui, Framer Motion
- Sempre use TypeScript
- Sempre use componentes do shadcn/ui quando disponível
- Sempre use Tailwind para estilização
- Sempre use Framer Motion para animações
- Ícones: sempre use lucide-react
- Gráficos: sempre use recharts
- Tabelas: sempre use @tanstack/react-table
- Formulários: sempre use react-hook-form com zod
- Notificações: sempre use sonner
- Estilo visual: moderno, limpo, profissional, fundo escuro
